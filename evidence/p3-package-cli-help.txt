### hermes plugins install --help
⚠ install out of sync (ffmpeg: not installed or outdated; node: not installed or outdated; npm: not installed or outdated; ripgrep: not installed or outdated) — run `hermes pm install`
usage: hermes plugins install [-h] [--force] [--ref COMMIT_SHA]
                              [--allow-removed] [--no-deps | --yes-deps]
                              [--enable | --no-enable]
                              identifier

positional arguments:
  identifier        Bare plugin catalog entry name (see `hermes plugins
                    search`), Git URL, or owner/repo shorthand (e.g.
                    anpicasso/hermes-plugin-chrome-profiles)

options:
  -h, --help        show this help message and exit
  --force, -f       Reinstall over an existing plugin (from the same source,
                    your untracked files are kept)
  --ref COMMIT_SHA  Install exactly one immutable 40-character Git commit SHA
  --allow-removed   DANGEROUS: bypass the catalog removed-plugin blocklist
                    check
  --no-deps         Download without dependency consent and leave disabled;
                    cannot replace an active plugin
  --yes-deps        Answer the Python dependency consent question yourself, so
                    non-interactive installs (SSH automation, CI, Docker
                    entrypoints) finish in one run instead of being refused
  --enable          Auto-enable the plugin after install (skip confirmation
                    prompt)
  --no-enable       Install disabled (skip confirmation prompt); enable later
                    with `hermes plugins enable <name>`
